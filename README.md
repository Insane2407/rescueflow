# FlowRescue AI

Build a premium, highly polished, visually stunning landing page and web app UI for a hackathon project called "FlowRescue".

PROJECT:

FlowRescue is an AI-powered workflow recovery and automation platform. It monitors digital workflows, detects when a workflow fails or gets stuck, diagnoses the probable cause using AI, generates a recovery plan, and safely resumes the workflow with minimal human intervention.

CORE TAGLINE:

"When workflows fail, FlowRescue doesn't just alert you. It rescues them."

IMPORTANT:

This is a hackathon project, so the website should LOOK like a production-grade AI startup product while remaining realistic and understandable. The visual quality should be extremely high.

DESIGN DIRECTION:

Create a cinematic, futuristic but professional website inspired by premium products such as Linear, Vercel, Stripe, Raycast and modern AI infrastructure platforms.

Do NOT make it look like a generic admin dashboard or a generic AI website.

Use:

- Dark premium background

- Subtle glassmorphism

- Soft gradients

- Elegant typography

- Thin borders

- Subtle glowing effects

- Depth and layered UI

- Smooth transitions

- 3D-inspired workflow objects

- Realistic lighting

- High-quality micro-interactions

- Sophisticated animations

- Plenty of whitespace

Avoid:

- Excessive neon

- Cartoonish graphics

- Cheap-looking gradients

- Too many colors

- Excessive rounded cards

- Generic stock illustrations

- Unnecessary animations everywhere

COLOR SYSTEM:

Primary background: near-black / deep charcoal

Secondary surfaces: dark graphite

Primary accent: electric blue

Secondary accent: violet

Success: emerald green

Failure: red

Warning: amber

Text: white and cool gray

The interface should feel like an AI emergency-response/control system for digital workflows.
